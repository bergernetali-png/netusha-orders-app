# מערכת ניהול הזמנות — NETUSHA

אפליקציה עצמאית (לא קשורה לאתר) לניהול כל ההזמנות שלך במקום אחד: פרטי לקוח, פריטים ומיתוג, תאריך אספקה, מלאי, מחיר ורווח אוטומטי, סטטוס תשלום וקבלה. Node.js טהור, בלי ספריות חיצוניות — בדיוק כמו האתר.

## מה יש באפליקציה

- **דשבורד**: כמה הזמנות פתוחות, הכנסות ורווח החודש, אחוז רווח ממוצע, רשימת "דורש תשומת לב" (פריטים שחסרים במלאי ולא הוזמנו מספק), ורשימת משלוחים קרובים עם סימון איחור/היום/מחר — כדי שלא תפספסי הזמנה.
- **כל ההזמנות**: טבלה עם חיפוש וסינון לפי סטטוס, וייצוא ל-CSV (נפתח באקסל).
- **הזמנה חדשה / עריכה**: פרטי לקוח, רשימת פריטים (כל פריט: כמות, עלות, מחיר מכירה, האם במלאי, ואם לא — האם הוזמן מספק ומתי צפוי להגיע), עלויות נוספות (אריזה, זמן הכנה, משלוח, עלות אחרת), סטטוס תשלום, וסימון "קבלה הוצאה". **הרווח מחושב אוטומטית וחי** תוך כדי מילוי הטופס.
- **הגדרות**: תעריף שעתי לחישוב עלות זמן הכנה, עלות אריזה ברירת מחדל, וכפתורי גיבוי/ייצוא.
- **סיכום להדפסה**: לכל הזמנה יש עמוד סיכום נקי שאפשר להדפיס או לשמור כ-PDF (מהדפדפן) ולתת ללקוחה.

חשוב: הסימון "קבלה הוצאה" הוא **תזכורת פנימית בלבד** — הוא לא מחליף הוצאת קבלה/חשבונית רשמית דרך מערכת חשבוניות מוסמכת (למשל icount, Green Invoice וכו'). לצורך מע"מ ודיווח למס הכנסה יש להמשיך להשתמש במערכת החשבוניות הרגילה שלך.

## איך פותחים את המערכת (הכי פשוט)

לוחצים פעמיים על הקובץ **"הפעלת המערכת.bat"** שנמצא בתיקייה הזו. ייפתח חלון שחור (אל תסגרו אותו — הוא "המנוע" שמריץ את המערכת), ואחריו יופתח הדפדפן אוטומטית עם מסך הכניסה. כשרוצים לכבות — פשוט סוגרים את החלון השחור.

בהפעלה ראשונה בלבד, אם אין על המחשב Node.js מותקן, הקובץ יגיד לכם זאת ויפנה אתכם ל-nodejs.org להתקנה (חד-פעמי, כמה דקות).

הסיסמה הראשונית (ברירת מחדל, אם לא הוגדרה אחרת): `netusha-orders-2026`.

### הרצה ידנית (למי שנוח עם שורת פקודה)

```
node server.js
```

האפליקציה תרוץ על http://localhost:3000.

## נתונים לדוגמה

בקובץ `data/orders.json` יש שתי הזמנות לדוגמה (מסומנות בשם "לקוחה לדוגמה — אפשר למחוק") שנועדו להמחיש איך נראית התראת "צריך להזמין מספק" ואיך נראה חישוב רווח מלא. אפשר למחוק אותן מתי שנוח — מהדשבורד/מרשימת ההזמנות, כפתור מחיקה בתוך כל הזמנה.

## שינוי סיסמה (חשוב לפני שמעלים לאינטרנט!)

1. העתיקו את הקובץ `.env.example` לקובץ בשם `.env`.
2. שנו את הערך של `ADMIN_PASSWORD` לסיסמה משלכם.
3. שנו גם את `SESSION_SECRET` למחרוזת אקראית (אפשר להריץ `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` ולהדביק את התוצאה).
4. הפעילו מחדש את השרת.

**אל תשאירו את הסיסמה המובנית כברירת מחדל אם האפליקציה עולה לאינטרנט** — כל מי שיודע אותה יוכל להיכנס.

## גיבוי הנתונים

כל המידע נשמר בקבצים פשוטים בתיקיית `data/` (`orders.json`, `settings.json`). זה נוח ופשוט, אבל המשמעות היא שאתן אחראיות לגבות אותו:

- בעמוד **הגדרות** יש כפתור "הורדת גיבוי מלא (JSON)" — מומלץ להוריד גיבוי אחת לכמה ימים, ובוודאי לפני כל שינוי גדול.
- יש גם ייצוא ל-CSV של כל ההזמנות, נוח להעביר לרואה חשבון או לשמור באקסל בנפרד.

## העלאה לענן — כמה שכדאי לדעת לפני שבוחרים

האפליקציה בנויה כך שאפשר להריץ אותה בכל שירות שתומך ב-Node.js. שתי נקודות שחשוב להבין **לפני** שבוחרים היכן לארח אותה:

1. **שמירת נתונים לאורך זמן**: חלק משירותי הענן החינמיים "מוחקים" את הקבצים בכל הפעלה מחדש של השרת (זה נקרא "ephemeral filesystem"). זה מסוכן לאפליקציה כמו זו, שכל ההזמנות שלך נשמרות כקבצים. **חובה לוודא שהשירות שבוחרים כולל "Persistent Disk" / "Volume"** (כמעט כל השירותים המומלצים למטה מציעים את זה, לפעמים בתשלום קטן של כמה דולרים בחודש).
2. **סיסמה אמיתית**: לפני שמעלים בפועל, לבצע את שלב "שינוי סיסמה" למעלה.

**אפשרויות מומלצות** (כולן תומכות ב-Node.js ובדיסק קבוע):
- **Railway** (railway.app) — פשוט להתחלה, יש שכבת חינם מוגבלת ואז תשלום זול לפי שימוש.
- **Render** (render.com) — יש שכבת חינם לאפליקציות, ותוספת דיסק קבוע בתשלום קטן.
- **Fly.io** — גמיש יותר, דורש קצת יותר היכרות טכנית.

בכל השירותים האלה התהליך בגדול דומה: יוצרים חשבון, מחברים את תיקיית הפרויקט (או מעלים אותה), מגדירים את משתני הסביבה (`ADMIN_PASSWORD`, `SESSION_SECRET`), ומוודאים שיש דיסק קבוע שמצביע לתיקיית `data/`. זהו שלב שדורש הרשמה לחשבון בשירות חיצוני ופרטי תשלום — משהו שכדאי שתעשי בעצמך; אני יכול להנחות אותך צעד-צעד כשתרצי להתחיל.

## מבנה הפרויקט

```
server.js          — השרת והראוטים
lib/                — לוגיקה משותפת (בסיס נתונים, אימות, חישוב רווח, קבועים)
views/              — תבניות ה-HTML
public/css, public/js — עיצוב וקוד צד-לקוח
data/               — כל הנתונים (orders.json, settings.json) — זה מה שצריך לגבות
```
